# 연봉 실수령액 계산기

연봉을 입력하면 2026년 기준 4대보험 요율과 근로소득세 계산 방식을 반영해 월 실수령액을 계산해주는
정적 웹사이트입니다. 서버·DB·API 호출이 전혀 없는 순수 클라이언트 계산이라 Vercel 무료 플랜으로
운영 비용 0원으로 배포할 수 있어요.

## 폴더 구조

```
salary-calculator/
├── index.html                  # 계산기 페이지
├── privacy.html                # 개인정보 처리방침 템플릿 (애드센스 심사 전 내용 채우기)
├── style.css
├── js/salary-calc.js           # 계산 로직 (순수 함수, 요율 상수는 파일 상단)
├── js/salary-calculator-ui.js  # 입력폼 ↔ 계산 로직 연결
├── test/salary-calc.test.js    # 계산 로직 검증 (npm test)
├── CLAUDE.md                   # Claude Code 인수인계 문서
└── package.json
```

## 계산 기준 (2026년)

- **4대보험 (근로자 부담분)**: 국민연금 4.75%(기준소득월액 41만~659만원), 건강보험 3.595%,
  장기요양보험(건강보험료의 13.14%), 고용보험 0.9%
- **소득세**: 국세청 근로소득 간이세액표의 산출 방식(총급여 → 근로소득공제 → 근로소득금액 →
  인적공제 → 과세표준 → 8단계 누진세율 → 근로소득세액공제 → 자녀세액공제)을 그대로 재현한
  근사 계산이에요. 실제 간이세액표 조회 결과나 연말정산 금액과는 소액 차이가 날 수 있습니다
  (페이지에도 안내 문구가 있어요).
- 매년 요율과 세법이 바뀌므로 연초에 `js/salary-calc.js` 상단 상수를 갱신해야 해요.

## 로컬 확인 / 배포

```bash
npm test                          # 계산 로직 검증
python -m http.server 8000        # http://localhost:8000 에서 확인
```

Vercel에서 이 저장소를 Import하면 정적 사이트로 바로 배포돼요 (환경변수 필요 없음).

## 애드센스 신청 전 체크리스트

- `privacy.html`의 `[연락처 이메일을 입력하세요]`, `[YYYY-MM-DD]`를 실제 정보로 채우기
- 도메인 연결 후 신청. 승인 전에는 `index.html`의 `.ad-slot` 영역이 HTML 주석으로 비활성화돼 있고,
  승인 후 주석을 해제해 광고 코드를 넣으면 돼요.
